# ARCHIVE — DEPRECATED / NON-PRODUCTION

This directory preserves historical Elite Dispatcher Academy artifacts that have been superseded, deprecated, duplicated, or removed from the live production path.

## Hard rule
Nothing under `ARCHIVE-DEPRECATED/` is authoritative student curriculum, instructor curriculum, assessment, simulation release material, current production status, or completion evidence.

Archived material is retained only for provenance, historical comparison, recovery, and audit traceability.

Current authority remains in the live numbered production folders and `00-ACADEMY-MASTER/` controls.

## Disposition labels
- SUPERSEDED — replaced by a newer authoritative control/artifact.
- DEPRECATED — intentionally removed from current use.
- DUPLICATE — redundant copy with no live-authority purpose.
- HISTORICAL SNAPSHOT — accurate for an earlier date but not current truth.

See `DEPRECATION-REGISTER.md` for movement records.
