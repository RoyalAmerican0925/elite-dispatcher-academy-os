# Module 08 — Broker Discovery Call Sheet

**Purpose:** Turn a broker call into a controlled information-and-negotiation event rather than a rate-only exchange.

**Point of use:** During OPEN → QUESTION → LISTEN → VERIFY → SUMMARIZE → POSITION.

**Competency evidence:** M08-C04, C05, C06, C10, C11.

## Self-Negotiation Check
- Did broker respond to the last counter? YES / NO
- Am I about to lower my position without new information, movement, clarification, or a deliberate trade? YES / NO
- If YES, stop and identify why movement is justified.

## Discovery Summary Before Positioning

- Broker constraints/statements:
- Verified leverage:
- Position still valid? YES / NO / VERIFY
- Next action: COUNTER / QUESTION / VERIFY / DECLINE / ESCALATE

**Instructor/practical use:** Evaluates whether the learner asks questions that reduce decision uncertainty, separates statements from facts, and listens before conceding.
