## Response

☐ No red flags — proceed normally
☐ One or more red flags — **STOP → VERIFY** through a trusted/appropriate channel
☐ Verification could not resolve the concern — **ESCALATE**

**REMINDER:** Do not accuse anyone of fraud based on a single indicator, or based on this checklist alone. A duplicate posting is not automatic proof of double brokering. A payment-redirection request is not automatic proof of a scam — it's a reason to verify through a trusted channel before acting. If verification doesn't resolve the concern, escalate rather than deciding it yourself.
