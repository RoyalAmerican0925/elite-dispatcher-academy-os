## Change control
For each revised document:
- Compare against prior version.
- Record every material change discovered.
- Record who supplied the revision and when.
- Keep prior version for audit history.
- Never alter a received document to make it match the expected terms.

**Rule:** Version control is evidence control. A familiar filename is not proof that a file is current.
