## Driver-facing handoff
Communicate only verified M09 booking facts needed for the next workflow. Clearly separate:
- booked facts;
- special document/operating instructions as written;
- items requiring M10/M11 review;
- office-only notes that should not be represented as driver instructions.

## Final packet control
- [ ] Every active document matches correct load and carrier.
- [ ] Current version is identified.
- [ ] Superseded/conflicting versions are excluded from active driver packet.
- [ ] No material booking discrepancy remains unresolved.
- [ ] Authority/approval requirements are satisfied.

**Rule:** A dispatch packet is controlled evidence, not a folder dump.
