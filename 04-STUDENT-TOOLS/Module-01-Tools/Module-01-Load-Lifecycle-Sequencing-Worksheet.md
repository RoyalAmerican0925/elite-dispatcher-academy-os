# Elite Dispatcher Academy — Module 01 Load Lifecycle Sequencing Worksheet

**Module:** 01 — Dispatcher Foundations and Industry Framework  
**Purpose:** Practice tracing a freight movement from shipment need through carrier payment documentation.

## Part A — Put the Load in Order

Number these events from **1 (first)** to **7 (last)**.

- ___ Carrier submits invoice and proof-of-delivery documentation for payment.
- ___ Driver delivers the freight and obtains delivery documentation.
- ___ Shipper has freight that needs transportation.
- ___ Carrier/dispatcher evaluates and books the load.
- ___ Driver picks up the freight and pickup documentation is created or signed.
- ___ Broker or direct shipper tenders/arranges the load with the carrier.
- ___ Dispatcher coordinates the assigned truck, driver, timing, and load movement.
