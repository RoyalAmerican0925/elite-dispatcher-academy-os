# Module 03 Weight & Dimension Verification Worksheet

**Status:** DRAFT_COMPLETE — QA required before PUBLICATION_READY
**Companion to:** `02-CURRICULUM/Module-03/Student-Manual-Part-02.md` §§17–21 and `Part-03.md` §27 (Weight-Margin Relationship)
**Purpose:** Work through the actual numbers for a proposed load — gross weight, axle distribution, and dimensions — rather than relying on a single figure.

**IMPORTANT:** This worksheet does not replace the full Load Fit Verification Checklist. It isolates the weight/dimension math specifically because that's where the module's core mistake ("under 80,000 lb = legal") happens most often.

---

## Weight

| Field | Value |
|---|---|
| Freight weight | ______ lb |
| Actual operating / tare weight of the specific tractor-trailer unit | ______ lb |
| **Total gross combination weight** (freight + tare) | ______ lb |
| Federal Interstate gross baseline | 80,000 lb |
| Is total gross weight under the baseline? | ☐ Yes ☐ No |

**Available gross-weight margin** = applicable gross limit − actual operating weight before cargo = ______ lb

**REMINDER:** This margin is a starting point, not "legal payload." It does not confirm axle legality by itself.

## Axle Distribution

| Field | Value |
|---|---|
| Weight on steer axle | ______ lb |
| Weight on drive tandem (or single axle, as applicable) | ______ lb |
| Weight on trailer tandem (or single axle, as applicable) | ______ lb |
| Federal single-axle limit | 20,000 lb |
| Federal tandem-axle limit | 34,000 lb |
| Is every individual axle/tandem group within its own federal limit? | ☐ Yes ☐ No ☐ Not yet confirmed |

**REMINDER:** A combination can be under the 80,000 lb gross baseline and still have an illegal axle group. Gross weight and axle distribution are two separate checks — both must pass independently.

| Trailer nominal size (as advertised) | ______ |
| Trailer actual usable interior length / width / height | ______ / ______ / ______ |
| Door / opening clearance | ______ |
| Does freight fit within usable interior dimensions? | ☐ Yes ☐ No ☐ Not yet confirmed |
| Does freight fit through the door/opening? | ☐ Yes ☐ No ☐ Not yet confirmed |
| Is freight width over 102 inches (National Network figure)? | ☐ Yes ☐ No |

If freight width exceeds 102 inches: this is NOT automatically illegal, and is NOT automatically permittable. Route to STOP/VERIFY — confirm applicable states/routes, permit requirements, and equipment before concluding either way.

## Conclusion

☐ Weight and dimensions both confirmed within legal limits — proceed to remaining checklist items
☐ A weight or dimension issue was identified — CORRECTION REQUIRED BEFORE MOVEMENT, or escalate for specialized/permit review
☐ Information is still missing — do not book; request the missing figures first
