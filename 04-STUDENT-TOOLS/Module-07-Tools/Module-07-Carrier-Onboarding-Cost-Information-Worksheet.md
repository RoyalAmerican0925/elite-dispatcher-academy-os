**Status:** DRAFT_COMPLETE — QA required before PUBLICATION_READY
**Companion to:** `02-CURRICULUM/Module-07/Student-Manual-Part-02.md` §10 (Carrier-Specific Costs)

Use this worksheet once, during carrier onboarding, to record the carrier's own reported cost information. This worksheet does not calculate the carrier's break-even point — it only records what the carrier reports, for the dispatcher's reference when evaluating future loads. All figures below are the carrier's own reported numbers, not dispatcher-calculated ones.

**IMPORTANT:** This worksheet exists to record what the carrier tells you, so that future load evaluations can be discussed with the carrier's actual situation in mind.
