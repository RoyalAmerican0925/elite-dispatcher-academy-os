## Red Flags That Should Trigger Extra Caution

- Urgency ("update immediately," "send today")
- Request arrives from an unfamiliar number, or an unverified new contact method
- Request conflicts with an existing Notice of Assignment (NOA) on file — see Module 04 §11
- Request comes from a "familiar-looking" email address you haven't independently re-verified for this specific change (a familiar sender does not defeat business-email-compromise risk)

## If Instructions Conflict

If payment instructions conflict (e.g., an existing NOA says one thing, a new message says another):

☐ STOP. Do not redirect funds.
☐ Verify through previously trusted contact information.
☐ Confirm with the appropriate parties (both the carrier and, if applicable, the factor).
☐ Escalate unresolved conflicts rather than making a unilateral call.

**REMINDER:** Do not attempt to resolve legal ownership of a receivable yourself. If a genuine dispute exists about who is entitled to payment, that is outside dispatcher-level judgment — escalate.
