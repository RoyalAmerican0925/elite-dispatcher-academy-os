# Module 08 — Rate Negotiation and Broker Communication Design

**Status:** APPROVED DESIGN — PRODUCTION AUTHORIZED
**Date:** 2026-09-04

## Employment outcome
By completion, the student can prepare for a broker rate conversation, establish a carrier-specific negotiation position using Module 07 economics, communicate professionally, obtain and clarify material load facts, make evidence-supported rate/counteroffer decisions, negotiate compensation and relevant terms without misrepresentation, document the conversation, recognize stop/escalation points, and hand an agreed opportunity into Module 09 for formal booking/document review.

## Operating framework
**PREPARE → VERIFY FACTS → SET POSITION → OPEN → QUESTION → LISTEN → COUNTER → TRADE → CONFIRM → DOCUMENT → ACCEPT / DECLINE / ESCALATE**

Negotiation is taught as occupational decision-making, not memorized scripts.

## Boundaries and dependencies
Imports Module 02 agency/legal boundaries, Module 06 verification discipline, and Module 07 profitability mathematics. Module 08 does not duplicate broker-fraud investigation, profitability instruction, formal rate-confirmation processing, HOS calculation, or booking documentation. Module 09 owns formal booking, rate-confirmation, and dispatch-document controls.

## Competency families
- Prepare from verified load/carrier facts.
- Convert Module 07 economics into a supplied carrier-specific negotiating position.
- Distinguish asking, target, floor/minimum and walk-away positions.
- Ask purposeful discovery questions before commitment.
- Identify broker constraints, missing facts and assumptions.
- Construct evidence-supported counters.
- Use truthful leverage; never fabricate competing offers, truck facts or market claims.
- Make conditional concessions/trades rather than uncontrolled concessions.
- Clarify agreement-specific accessorial and operating terms without inventing universal amounts.
- Maintain professional communication under resistance.
- Recognize supplied authority boundaries and escalate when required.
- Confirm what is and is not agreed.
- Document the negotiation and hand off to Module 09 without representing a verbal negotiation as completed booking.
- Decline professionally when the opportunity does not meet supplied carrier requirements.

## Assessment architecture
Embedded call drills → diagnostic Knowledge Check → progressive negotiation lab → module exam → graded Broker Negotiation Desk practical → remediation → SIM-008 Broker Negotiation Lab → competency record.

Critical-failure candidates include knowingly accepting below a supplied carrier minimum without authorization; fabricating leverage or competing offers; materially misrepresenting truck/driver facts; committing outside supplied authority; treating unresolved material terms as agreed; and representing verbal negotiation as completed booking before Module 09 controls.
