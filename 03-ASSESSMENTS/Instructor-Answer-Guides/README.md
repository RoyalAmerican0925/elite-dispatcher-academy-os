## Control Rules

- A Drive filename containing `FINAL` does not make the repository asset PUBLICATION_READY.
- Instructor-only answers, scoring guidance, and scenario classifications must not appear in student-facing materials.
- AI names, chat transcripts, handoff prompts, email-style coordination headers, and context-packet language are production metadata, not instructor content.
- Each guide must map answers to taught objectives and use stable module, fact, and scenario identifiers.
- Legal, regulatory, FMCSA-system, platform-specific, and other time-sensitive claims require authoritative sources and a current as-of-date review.
- Superseded guides belong in `99-ARCHIVE/`; do not delete historical versions.

## Publication Gate

A guide may advance beyond DRAFT_COMPLETE only after provenance, duplicate-version, content, terminology, dependency, factual/source, instructional, formatting, and separation-of-audiences checks are recorded.
