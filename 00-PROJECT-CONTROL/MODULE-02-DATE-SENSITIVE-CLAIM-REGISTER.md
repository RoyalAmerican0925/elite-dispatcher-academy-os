## Why This Register Exists Separately

The student manual and instructor guide both flag these items inline as "current-date" or "verify before publication" notes. This register exists so that:

1. A reviewer can re-verify every date-sensitive claim in one pass without re-reading the entire module.
2. Each claim's revision risk is explicitly rated, so the highest-risk figure (the civil penalty amount, which has already moved twice in 2026) gets prioritized ahead of lower-risk figures like the $75,000 financial-security baseline.
3. Future revisions to any one figure can be tracked here without requiring a full manual rewrite each time.
