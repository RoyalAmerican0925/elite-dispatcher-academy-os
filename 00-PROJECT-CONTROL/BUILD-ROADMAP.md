# Build Roadmap

## Stage 1 — Recovery and Repository Control
Recover prior plans, module files, assessments, templates, simulations, and architecture notes. Establish naming, status, provenance, terminology, IDs, dependencies, and acceptance rules.

## Stage 2 — Core Academy Completion
Complete the dispatcher curriculum, syllabus, student manuals, instructor references, worksheets, checklists, templates, SOPs, flashcards, quizzes, module exams, answer keys, practical assessments, and final exam.

## Stage 3 — Scenario and Simulation Layer
Build progressive practice for load selection, RPM/profit analysis, broker verification, rate negotiation, trip planning, delay management, documentation, fraud recognition, and dispatch decision-making.

## Stage 4 — Commercial Product Packaging
Create the student journey, onboarding, completion requirements, certificate workflow, content delivery structure, QA gate, and launch package.

## Stage 5 — EAOS Foundation
Convert the production workflow into reusable architecture for content lifecycle management, assessments, simulations, dashboards, version control, QA, and AI orchestration.

## Stage 6 — TKE Expansion
Normalize the transportation knowledge base, terminology, sources, regulatory updates, dependency graph, manifest, and reusable transportation-domain data models.

## Build Direction
Each stage should preserve compatibility with the next. Near-term deliverables should not be thrown away when EAOS/TKE development begins.
