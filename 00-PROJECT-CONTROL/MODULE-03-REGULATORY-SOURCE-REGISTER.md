## Notes on Source Hierarchy

This module consistently distinguishes six categories, and content is labeled accordingly:

1. **FEDERAL REQUIREMENT** — binding federal statute/regulation (23 U.S.C., 23 CFR, 49 CFR citations).
2. **STATE-SPECIFIC REQUIREMENT** — varies by state (e.g., permitted semitrailer length above the 48-foot federal floor, height limits, overwidth permit processes).
3. **INDUSTRY PRACTICE** — common convention, not a binding legal rule (e.g., "hotshot" terminology, typical dock-loading).
4. **TYPICAL EQUIPMENT SPECIFICATION** — common but non-universal figures (e.g., 53-foot trailers as common industry equipment).
5. **CARRIER-SPECIFIC FACT** — must be verified for the actual unit involved (e.g., actual tare weight, actual usable interior dimensions).
6. **COURSE SAFETY PRACTICE** — this academy's own risk-control teaching (e.g., DO NOT BOOK FROM WEIGHT ALONE; STOP/VERIFY/ESCALATE).
