# Module 05 — Premium Depth Gap Audit

**Date:** 2026-09-01

**Module:** 05 — Load Boards & Freight Sourcing

## Executive finding

Module 05 has a strong factual and safety-conscious base, seven student-manual parts, nine operational tools, scenario work, and the repaired C-013 verification/rate-confirmation layer. It is not a thin outline. However, it still reads in several places as a reference manual plus scenarios rather than a fully coached dispatch-desk workflow.

**Premium verdict:** `SUBSTANTIAL BASE — DEEPEN/REPAIR BEFORE PREMIUM ALIGNMENT`

The strongest existing spine is:

**FIND → SCREEN → FLAG → FIRST-PASS VERIFY → ROUTE FOR DEEPER VERIFICATION**

For premium occupational training, the operational spine should be made explicit across the manual and tools as:

**PROFILE THE TRUCK → BUILD THE SEARCH → TRIAGE RESULTS → READ THE POSTING → CLASSIFY GAPS → SCREEN FIT → VERIFY AVAILABILITY/DETAILS → RECORD THE CONTACT → COMPARE CANDIDATES → REVIEW WRITTEN TERMS → HAND OFF UNRESOLVED RISK**

This does not replace the existing Module 05/06 boundary. It makes the work sequence teachable and observable.

## What is already strong — KEEP

### 1. Posting-as-lead mental model
KEEP. The manual correctly refuses to treat a visible posting as proof of availability, completeness, carrier qualification, broker legitimacy, acceptable rate, or booking. This is occupationally useful and should remain a repeated decision principle.

### 2. Carrier-profile-driven search
KEEP and DEEPEN. Module 05 correctly imports the carrier/driver/equipment profile from Module 04 and rejects universal search-radius rules. This is the right foundation.

### 3. Missing-information discipline
KEEP. `do not assume → identify the gap → verify → document → continue or reject` is one of the strongest existing workflows.

### 4. Posting age and duplicate-posting nuance
KEEP. The manual avoids false universal age thresholds and avoids diagnosing double brokering from similar postings alone.

### 5. Module 02 boundary transfer
KEEP. Shipper-direct sourcing is correctly tied back to the carrier-side agency/broker boundary instead of being presented as unrestricted solicitation.

### 6. Equipment/driver qualification transfer
KEEP. Module 03/04 fit concepts are correctly applied at sourcing, including hazmat endorsement mismatch and partial-load dimensional uncertainty.

### 7. C-013 additions
KEEP. Rate-confirmation discrepancy review, signing-authority limits, entity-versus-contact distinction, sourcing-stage red flags, introductory credit/factoring distinctions, HOS timing awareness, account security, and accurate broker-call representation materially improve the module.

### 8. Module 06 boundary
KEEP and sharpen. Module 05 flags and first-pass verifies; Module 06 owns deeper identity/authority/contact/fraud/payment-path investigation.

## Premium gaps and required actions

### GAP A — Search construction is listed, not sufficiently demonstrated
**Decision: DEEPEN**

The manual names search parameters but does not yet give the learner enough coached practice translating a real Module 04 carrier profile into a search strategy.

Add a worked search-profile translation showing truck location, equipment, availability, carrier lane preferences, restricted regions, home-time commitment, origin-deadhead tolerance, appointment constraints and special capabilities. Show which facts become hard filters, soft preferences, and verification questions.

**Target:** Student Manual Part 01, Sections 6–7; Load Search Worksheet.

### GAP B — Result triage needs an explicit desk method
**Decision: ADD**

The current search workflow jumps from filters/results to shortlist/review without teaching how a dispatcher handles a screen full of candidates under time pressure.

Add a triage method that separates immediate reject, promising/inspect now, verify, and lower-priority/hold. Posting age may affect priority but cannot be a universal rejection threshold.

**Target:** Student Manual Parts 01–02; Load Screening Checklist; Load Search Activity Log.

### GAP C — Posting literacy needs a worked field-by-field specimen
**Decision: DEEPEN**

The manual lists posting fields and classification states but premium instruction should make the learner read an imperfect fictional posting, annotate each material field, identify conflicts and convert gaps into call questions.

**Target:** Student Manual Part 01 after Section 9; Broker Call Sheet/Load Screening Checklist.

### GAP D — KNOWN/MISSING/UNCLEAR/VERIFY and KNOWN/UNKNOWN/VERIFY language needs normalization
**Decision: REPAIR**

Current Academy controls use KNOWN / UNKNOWN / VERIFY in several places, while Module 05 Section 9 uses KNOWN / MISSING / UNCLEAR / VERIFY. These are not inherently incompatible, but the relationship must be explicit to avoid competing taxonomies.

Recommended Module 05 field state: **KNOWN / MISSING / UNCLEAR / VERIFY** for posting-field review, with **UNKNOWN** as the umbrella state used in cross-module decision controls. Explain the mapping once.

**Target:** Student Manual Part 01; Module 05 tools using state labels.

### GAP E — Broker-call workflow needs more than a model opening line
**Decision: DEEPEN**

The professional opening is useful, but the learner needs a call sequence: identify self/carrier/load; confirm availability; close missing fields; clarify conflicting fields; capture rate and special terms; confirm next action; document source/time/contact. The module should also teach what not to claim or promise.

**Target:** Student Manual Part 07, Section 33; Broker Call Sheet.

### GAP F — Candidate comparison is under-taught before Module 07
**Decision: DEEPEN WITH BOUNDARY**

Module 05 correctly avoids full profitability mathematics, but a dispatcher still needs a sourcing-stage comparison framework. Teach comparison using operational fit, origin deadhead, timing exposure, destination positioning, missing information, availability status, carrier preferences and whether deeper verification is required. Do not calculate full profit here.

**Target:** Student Manual Part 07, Section 27; Load Comparison Worksheet.

### GAP G — Written-terms review should be tied to an evidence trail
**Decision: DEEPEN**

Part 07 correctly says STOP on material discrepancy. Add the operational record: what was discussed, what the written document says, discrepancy classification, who was contacted, what correction/clarification was received, who has authority to proceed, and final disposition. Never teach the student to silently edit a broker document.

**Target:** Student Manual Part 07, Section 26; Rate Confirmation Review Checklist.

### GAP H — First-pass verification tools risk drifting into Module 06
**Decision: REPAIR/ROUTE**

The presence of a `Broker Verification Worksheet` and `Freight Fraud Red-Flag Checklist` in Module 05 can create scope confusion. Keep them only as **sourcing-stage first-pass/flagging records**, not full broker verification instruments. Their labels/instructions should explicitly route unresolved entity/contact/authority/payment risk to Module 06.

**Target:** Broker Verification Worksheet; Freight Fraud Red-Flag Checklist; STOP-VERIFY-ESCALATE tool.

### GAP I — Evidence logging is fragmented
**Decision: DEEPEN**

The activity log should capture enough evidence to reconstruct why a candidate was rejected, held, verified or advanced: source/platform, timestamp, load reference, contact, material missing/conflicting facts, action taken, disposition, and next module/handoff when relevant.

**Target:** Load Search Activity Log and related manual workflow.

### GAP J — Scenario lab is strong but too many scenarios reveal the classification immediately
**Decision: REPAIR IN PRACTICE/INSTRUCTOR LAYER**

The manual's worked scenarios are useful demonstrations. Premium practice must also give students unscaffolded or partially scaffolded cases before revealing the answer. Preserve demonstrations but ensure practical/instructor activities require independent classification and evidence.

**Target:** assessment/practical and Instructor Guide tasks, not necessarily deletion of existing worked scenarios.

### GAP K — Search-to-handoff continuity should be visible as one evolving dispatch file
**Decision: ADD**

The learner should experience a candidate moving from search result through posting review, call, fit screen, comparison, written-term review and either rejection/hold/handoff/advance. This becomes the instructional precursor to SIM-005 and prevents the module from feeling like disconnected facts.

**Target:** manual worked case plus Instructor Guide facilitation; later SIM-005 alignment.

### GAP L — Platform/current-date material requires isolated update control
**Decision: KEEP/CONTROL**

The current platform section is appropriately labeled current-date material. Preserve the dated, non-endorsement framing and ensure instructor/currentness notes require reverification before release after meaningful delay.

**Target:** source/currentness controls and Instructor Guide.
