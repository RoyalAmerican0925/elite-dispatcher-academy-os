# Product Dependency Map

## Core Evidence Chain
`Occupational competency → instruction → demonstration/example → guided practice → independent practice → assessment → practical → simulation → remediation if needed → competency record`

## Dependency Questions
For every competency:
1. Where is it explicitly taught?
2. Where does the student see a correct worked example or demonstration?
3. Where does the student practice it with support?
4. Where does the student perform it independently?
5. Which assessment produces evidence?
6. Does the practical require integrated use?
7. Does the simulation reproduce the judgment/workflow realistically?
8. What happens after an incorrect decision?
9. Where is mastery recorded?
10. Which later competency depends on it?

## Defect Classes
- **ORPHAN-INSTRUCTION:** taught but never meaningfully used or assessed.
- **UNTaught-ASSESSMENT:** assessed before adequate instruction/practice.
- **UNUSED-TOOL:** worksheet/job aid exists but is not integrated into workflow.
- **SIMULATION-GAP:** simulation expects a decision the course did not prepare the student to make.
- **LANGUAGE-GAP:** student must use professional terminology without instruction/reinforcement.
- **SOURCE-GAP:** source-sensitive claim lacks adequate authority/date control.
- **DUPLICATION:** repeated material adds no new competency or useful reinforcement.
- **HANDOFF-GAP:** module stops without explaining what happens next or where later depth occurs.

## Module Control Record
Each module's premium-depth audit should eventually record:
| Competency ID | Teach | Demonstrate | Practice | Assess | Practical | Simulation | Record | Later dependency | Status |
|---|---|---|---|---|---|---|---|---|---|

A blank cell is a defect to investigate, not something to conceal.
