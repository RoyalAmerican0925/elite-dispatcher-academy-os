Scale to a 100-point basis by dividing by 1.1 if a flat 100-point record is required elsewhere in the program's reporting.)

## Scoring Method

For each decision, award:

- **Full points** if the student's final answer (after any remediation) is correct
- **Half points** if the student required remediation to reach the correct final answer
- **Zero points** if the student's final answer remains incorrect after remediation (should be rare — escalate to direct instructor intervention per the Instructor Guide rather than simply recording a zero and moving on)

## Passing Threshold

Consistent with the program's diagnostic/formative assessment philosophy (see `03-ASSESSMENTS/PROGRAM-ASSESSMENT-SCORING-AND-REMEDIATION-POLICY.md`), this simulation is a reinforcement exercise, not a graded exam. There is no numeric passing threshold that blocks progress. **Completion rule:** all 13 decisions reach final-correct status (see Instructor Guide). The point totals above exist to give instructors a competency-level view of where a student needed the most remediation, not to gate advancement.

## No Module-Specific Critical Failure

Consistent with the existing Module 01 Practical Assessment, no critical-failure item is designated for this simulation. This is a deliberate continuity choice, not an oversight — Module 01 content does not carry the same safety/legal stakes as later modules (e.g., Module 03's axle-weight critical item, Module 04's hazmat-endorsement critical item), so inventing a critical-failure mechanic here would not reflect any genuine stakes in the underlying content.

## Remediation Rule

Any decision scored below full points should trigger the corresponding remediation path in the Instructor Guide before the student is considered complete. A student should not exit the simulation with unresolved incorrect answers.
