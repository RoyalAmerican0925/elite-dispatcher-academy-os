# SIM-001 Instructor Premium Addendum — Stages 7–8

**Instructor use only.**  
**Controls:** Stages 7–8 in the browser runtime and student premium addendum.

## Stage 7 expected evidence

### D14 — Document and lifecycle meaning
Expected mapping:
- broker pickup message → **information/communication — not itself proof of completed booking**;
- rate confirmation not yet issued → **commercial document state — pending/absent**;
- POD after delivery → **delivery evidence/document flow**;
- carrier invoice after billing conditions are satisfied → **billing/payment-flow document**.

Competencies: M01-C04, C05, C06, C07.

### D15 — KNOWN / UNKNOWN / VERIFY
Expected:
- Origin city: Omaha → **KNOWN** as supplied case evidence;
- Pickup timing → **VERIFY** because FCFS 08:00–13:00 conflicts with copied 10:30 appointment;
- Exact delivery appointment → **UNKNOWN**;
- Special instructions → **UNKNOWN**.

Competencies: M01-C06, C11, C13, C15.

Instructor must correct two common errors:
1. treating a blank field as “none”; and
2. silently choosing one conflicting source without verification.

### D16 — Interstate/intrastate nuance
Correct answer: **C**. The visible leg is inside Texas but the file lacks enough broader-movement facts for every categorical legal conclusion.

Competencies: M01-C09, C15.

## Stage 8 expected evidence

### D17 — Later-workflow handoff
Expected mapping:
- equipment/weight fit → M03;
- total-trip economics → M07;
- HOS/ELD feasibility → M11;
- formal booking/rate-confirmation review → M09.

Competencies: M01-C07, C14.

### D18 — STOP framework
Correct answer: **C**. The student should preserve the conflict/missing-data state, verify controlling information, document the result, then hand off to the correct next workflow.

Competencies: M01-C06, C11, C13, C14, C15.

Two consecutive incorrect attempts may trigger instructor review in the runtime. This is **not** a fabricated M01 critical-failure family. It is a foundation-level assumption-control safeguard.

## Remediation
When D13 or D18 shows repeated unsafe assumption behavior:
- preserve the first attempt;
- explain the reasoning failure rather than merely revealing the answer;
- use a materially different freight-file scenario for instructor reassessment;
- record corrected evidence separately in the completion record.

## Release boundary
Do not interpret mastery in this addendum as a commercial release claim. Browser/device/LMS/accessibility/durable-record QA remains separate.
