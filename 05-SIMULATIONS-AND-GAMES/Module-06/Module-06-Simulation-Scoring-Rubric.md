# SIM-006 — Scoring Rubric & Competency Map

**Purpose:** Evaluate SIM-006 consistently with the Module 06 practical.  
**Gate:** A preserved critical failure prevents clean SIM-006 competency clearance and requires instructor remediation/reassessment on a materially different case.

## Competency map
| Code | Observable competency | Meets standard |
|---|---|---|
| C01 | Classifies intake evidence | Separates observation, claim and unknown |
| C02 | Isolates claims before acting | Builds independent verification path |
| C03 | Verifies entity/current status | Limits evidence to what source proves |
| C04 | Separates entity from contact | Never infers caller authorization from active entity |
| C05 | Authenticates contact | Uses independently trusted callback |
| C06 | Cross-checks documents | Identifies actual mismatches and holds unresolved document |
| C07 | Interprets status evidence | Separates authority, BMC, factor signal and timing contexts |
| C08 | Handles duplicate ambiguity | Verification indicator ≠ automatic fraud conclusion |
| C09 | Protects payment path | HOLD + independent authentication |
| C10 | Resists pressure | No control bypass under urgency |
| C11 | Preserves evidence states | Entity/contact/document/payment/duplicate remain separate |
| C12 | Reclassifies risk | Updates decision when later evidence changes |
| C13 | Chooses disposition | Transaction-level DO NOT BOOK/ESCALATE when contradictions warrant |
| C14 | Builds handoff | Verified facts, contradictions, actions, stopped work, owner and next decision |

## Six controlling critical-failure families
- **CF1 — Payment redirection:** acts on unverified/contradicted payment change.
- **CF2 — Entity as contact proof:** treats legitimate/active entity as authorization of an unverified contact.
- **CF3 — Contact contradiction:** proceeds after trusted evidence establishes material contact contradiction.
- **CF4 — Inactive authority:** knowingly proceeds where required broker authority is verified inactive.
- **CF5 — Unsupported fraud conclusion:** declares fraud/double brokering solely from ambiguous/inconclusive indicators.
- **CF6 — Material mismatch bypass:** proceeds around unresolved/contradicted identity, document or payment evidence.

## Runtime evidence retained
For every decision:
- first-attempt response/correctness/timestamp;
- final response/correctness where retry is allowed;
- remediation-used state;
- competency family;
- critical-failure family if applicable;
- instructor-review state.

## Result labels
**COMPLETE** — required decisions completed with no preserved critical failure.  
**INSTRUCTOR_REVIEW_REQUIRED** — one or more critical failures preserved, even if the learner later selects the correct response on that same screen.  
**IN_PROGRESS** — required case work unfinished.

## Relationship to Module 06 Practical
The graded Practical remains **24/30 plus no critical failure**. SIM-006 does not replace that scoring system; it extends the same judgment rules into a progressive case and creates additional competency evidence.

A corrected same-screen response may show immediate recovery but does **not** erase critical-failure evidence. Critical reassessment must use a materially different fictional fact pattern and be recorded separately.
