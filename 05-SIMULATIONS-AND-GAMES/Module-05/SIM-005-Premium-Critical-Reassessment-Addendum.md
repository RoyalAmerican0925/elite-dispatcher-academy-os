# SIM-005 Premium Critical-Reassessment Addendum

**Status:** ACTIVE SIM-005 CONTROL — supersedes any older same-screen critical-clearing language.

## Purpose
This addendum aligns SIM-005 with the Module 05 Instructor Guide and Academy premium remediation standard.

## Rule
A critical family is not erased because the learner later selects the correct response on the original screen. The original trigger remains part of the competency record. Resolution requires transfer of the controlling principle to a materially different fact pattern.

## Reassessment administration
The browser runtime contains one alternate case per family in `runtime/critical-controls.js`. Each case changes the parties/facts while preserving the occupational principle. Instructors may administer the same controlled case in the browser or use a materially equivalent alternate case in a supervised environment.

The reassessment record must preserve:
- original trigger family and decision;
- original trigger timestamp/order;
- main-screen final mastery state;
- alternate reassessment response and result;
- resolution timestamp;
- unresolved/resolved status.
