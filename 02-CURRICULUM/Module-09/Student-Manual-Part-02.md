# Module 09 Student Manual — Part 02
## Rate Confirmation Anatomy & Material-Term Extraction

### Employment outcome
The learner can read a rate confirmation as a controlled booking document instead of scanning only the dollar amount.

## 1. What a rate confirmation is — and is not
In this Academy workflow, a rate confirmation is evidence of the broker/carrier booking terms supplied for the case. It is not interchangeable with:
- a load-board posting;
- a quote or negotiation note;
- a bill of lading;
- a proof of delivery;
- an invoice;
- a carrier setup packet.

Those records can contain overlapping facts, but they serve different purposes.

## 2. The extraction discipline
Use the Material-Term Extraction Worksheet and capture:
- document title/type;
- load/reference number;
- broker/customer identity;
- carrier identity;
- version/date/time/source;
- origin and destination;
- pickup/delivery dates, times and appointment language;
- equipment;
- commodity and weight when stated;
- rate and stated breakdown;
- accessorial/operating terms;
- tracking/check-call/document requirements;
- cancellation/TONU/detention/lumper language when present;
- payment/document submission language when present;
- signature/acceptance fields;
- unusual or ambiguous terms.

Do not teach any case-specific accessorial amount or trigger as a universal industry rule. Extract what the document actually says.

## 3. Materiality
A term is **material to M09 booking control** when a difference can change the carrier's agreed money, service obligation, load identity, equipment/commodity obligation, pickup/delivery commitment, documentation obligation, risk, or required authority.

A typo can be nonmaterial; a wrong load number can still be operationally dangerous if it causes the wrong document to be used. Classification depends on the supplied evidence and consequence, not the visual size of the error.

## 4. Worked extraction — fictional RC v1
Assume RC v1 states:
- Load NL-9041
- Northline Brokerage → Summit Lane Transport
- Dallas, TX pickup Tue 14:00
- Nashville, TN delivery Wed 10:00
- 53' dry van
- 39,000 lb packaged food
- linehaul $2,450
- driver assist required
- tracking link required before pickup
- signed acceptance requested

The extraction worksheet records every item. It does **not** yet decide whether each term matches M08. Extraction comes before reconciliation.

## 5. Why extraction and reconciliation are separate
If you compare while you are still reading, you tend to notice only expected facts. The professional sequence is:
1. extract the written document accurately;
2. identify its source/version;
3. then compare it to the controlled handoff.

This creates an audit trail and reduces confirmation bias.

## 6. Ambiguity handling
Examples:
- "FCFS" appears but M08 says appointment: classify for reconciliation; do not silently choose one.
- "Detention per broker policy": record the exact language and identify the referenced policy if material; do not invent a dollar amount.
- two PDFs have the same filename but different pickup times: treat as a version-control problem.
- carrier name is abbreviated: verify identity rather than assuming it is harmless.

## 7. Coached practice
You receive a confirmation showing the correct rate and lane but the wrong carrier legal name and a different delivery time.

Required actions:
- extract both discrepancies;
- do not mark the file booked;
- classify identity and delivery-time issues for reconciliation;
- obtain correction/clarification before using the document as the controlled dispatch source.

## 8. Common failures
- rate-only scanning;
- reading the document from memory instead of field by field;
- ignoring terms below the signature line;
- treating broker boilerplate as irrelevant without review;
- assuming the newest email attachment is automatically the controlling version;
- inventing meaning for abbreviations or blank fields.

### Part 02 operating rule
**Extract first. Reconcile second. Never let a matching headline rate hide a conflicting obligation.**
