# Elite Dispatcher Academy OS

This private repository is the source-of-truth for the Elite Trucking Dispatcher Course, the near-term academy build, and the long-term Elite Academy Operating System (EAOS) / Transportation Knowledge Engine (TKE) vision.

## Repository purpose

- Preserve the original course architecture and ultimate system vision.
- Separate the near-term sellable academy from the long-term platform build.
- Track completed curriculum, missing assets, dependencies, standards, and decisions.
- Provide one organized location for curriculum, assessments, student tools, simulations, knowledge architecture, software, and production controls.

## Build layers

1. **Near-term academy** — complete and launch a professional self-paced trucking dispatcher course.
2. **EAOS** — build the operating system for curriculum production, assessment, simulation, QA, and student/instructor experiences.
3. **TKE** — develop the larger transportation knowledge engine and reusable knowledge architecture.

See `00-PROJECT-CONTROL/MASTER-PLAN.md` for the controlling plan.
